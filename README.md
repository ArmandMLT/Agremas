# AGREMAS — Sitio Web Oficial

**Materiales, Maquinaria & Servicios · República Dominicana**

Sitio web moderno y profesional para AGREMAS, empresa especializada en soluciones para construcción e infraestructura.

## 🚀 Despliegue en Vercel

### Opción 1: Vercel CLI
```bash
npm i -g vercel
vercel --prod
```

### Opción 2: Vercel Dashboard (Recomendado)
1. Ve a [vercel.com](https://vercel.com) e inicia sesión con GitHub
2. Haz clic en **"Add New Project"**
3. Selecciona este repositorio
4. Haz clic en **"Deploy"** — Vercel detecta automáticamente que es un sitio estático

## 📁 Estructura del Proyecto

```
agremas/
```
